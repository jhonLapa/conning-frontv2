1. INTRODUCCIÓN
═══════════════════════════════════════════════════════════════════════════════

jsPDF es una librería JavaScript que permite generar archivos PDF directamente
en el navegador del cliente, sin necesidad de un servidor backend.

Características principales:
- Generación de PDFs en el navegador
- Soporte para texto, imágenes, formas y tablas
- Compatible con TypeScript
- Extensible mediante plugins (como jspdf-autotable para tablas)

3. CONCEPTOS BÁSICOS
═══════════════════════════════════════════════════════════════════════════════

3.1 SISTEMA DE COORDENADAS
---------------------------
- El origen (0, 0) está en la esquina SUPERIOR IZQUIERDA
- La unidad por defecto es en milímetros (mm)
- El tamaño de página por defecto es A4 (210mm x 297mm)

Ejemplo de coordenadas:
(0, 0)        →→→→→→→→→  X (horizontal)
  ↓
  ↓  (15, 20) es 15mm desde la izquierda
  ↓             y 20mm desde arriba
  ↓
  Y (vertical)

3.2 CREAR UNA INSTANCIA DE PDF
-------------------------------
```typescript
import jsPDF from 'jspdf';

const doc = new jsPDF();
// Por defecto: orientación 'portrait', formato 'a4', unidad 'mm'

// Con opciones personalizadas:
const doc = new jsPDF({
  orientation: 'portrait',  // 'portrait' o 'landscape'
  unit: 'mm',               // 'mm', 'cm', 'in', 'px'
  format: 'a4'              // 'a4', 'letter', [width, height]
});
```

3.3 POSICIONAMIENTO Y
-----------------------
La variable yPosition es crucial para controlar dónde dibujar cada elemento:

```typescript
let yPosition = 15; // Empezar a 15mm desde arriba

// Dibujar texto
doc.text('Hola', 15, yPosition);
yPosition += 10; // Mover 10mm hacia abajo para el siguiente elemento

// Dibujar otro texto
doc.text('Mundo', 15, yPosition);
yPosition += 10;
```

4. GENERACIÓN DE PDF SIMPLE
═══════════════════════════════════════════════════════════════════════════════

4.1 AGREGAR TEXTO
-----------------
```typescript
// Sintaxis básica:
doc.text(texto: string, x: number, y: number, opciones?: object);

// Ejemplos:
doc.text('Hola Mundo', 15, 20);

// Texto centrado
doc.text('Texto Centrado', 105, 20, { align: 'center' });
// 105 es el centro de una página A4 (210mm / 2)

// Texto alineado a la derecha
doc.text('Derecha', 195, 20, { align: 'right' });
```

4.2 CONFIGURAR FUENTES
----------------------
```typescript
// Cambiar tamaño de fuente
doc.setFontSize(16);
doc.text('Texto Grande', 15, 20);

doc.setFontSize(10);
doc.text('Texto Pequeño', 15, 30);

// Cambiar estilo de fuente
doc.setFont('helvetica', 'normal');  // normal
doc.setFont('helvetica', 'bold');    // negrita
doc.setFont('helvetica', 'italic');  // itálica
doc.setFont('helvetica', 'bolditalic'); // negrita e itálica
```

4.3 COLORES
-----------
```typescript
// Color de texto (RGB: valores 0-255)
doc.setTextColor(255, 0, 0); // Rojo
doc.text('Texto Rojo', 15, 20);

// Color de relleno (para formas)
doc.setFillColor(0, 255, 0); // Verde
doc.rect(15, 30, 50, 20, 'F'); // Rectángulo relleno

// Color de borde
doc.setDrawColor(0, 0, 255); // Azul
doc.rect(70, 30, 50, 20); // Rectángulo con borde
```

4.4 FORMAS GEOMÉTRICAS
----------------------
```typescript
// Rectángulo
// doc.rect(x, y, ancho, alto, estilo?)
doc.rect(15, 20, 50, 30);          // Solo borde
doc.rect(15, 20, 50, 30, 'F');     // Relleno (Fill)
doc.rect(15, 20, 50, 30, 'FD');    // Relleno + borde

// Línea
doc.line(15, 20, 100, 20); // De (15,20) a (100,20)

// Círculo
doc.circle(50, 50, 20); // Centro (50,50), radio 20
```

4.5 TEXTO MULTILÍNEA
--------------------
```typescript
// splitTextToSize divide texto largo en líneas que caben en un ancho
const texto = 'Este es un texto muy largo que necesita dividirse...';
const lineas = doc.splitTextToSize(texto, 180); // Ancho máximo 180mm
doc.text(lineas, 15, 20);
```

4.6 EXPORTAR/GUARDAR PDF
------------------------
```typescript
// Descargar el PDF
doc.save('mi-documento.pdf');

// Abrir en nueva pestaña
const pdfBlob = doc.output('blob');
const pdfUrl = URL.createObjectURL(pdfBlob);
window.open(pdfUrl, '_blank');

// Limpiar después de abrir
setTimeout(() => URL.revokeObjectURL(pdfUrl), 100);

// Obtener como Blob (para enviar al servidor)
const blob = doc.output('blob');
```

5. USO DE TABLAS CON jspdf-autotable
═══════════════════════════════════════════════════════════════════════════════

jspdf-autotable es un plugin que facilita la creación de tablas profesionales.

5.1 IMPORTACIÓN
---------------
```typescript
import jsPDF from 'jspdf';
import autoTable from 'jspdf-autotable';
```

5.2 TABLA BÁSICA
----------------
```typescript
const doc = new jsPDF();

autoTable(doc, {
  head: [['Nombre', 'Email', 'País']], // Encabezados
  body: [
    ['Juan', 'juan@email.com', 'Perú'],
    ['María', 'maria@email.com', 'Chile'],
    ['Pedro', 'pedro@email.com', 'Argentina'],
  ],
});

doc.save('tabla.pdf');
```

5.3 CONFIGURACIÓN AVANZADA
--------------------------
```typescript
autoTable(doc, {
  startY: 30,  // Posición Y donde empieza la tabla
  head: [['Columna 1', 'Columna 2', 'Columna 3']],
  body: [
    ['Dato 1', 'Dato 2', 'Dato 3'],
    ['Dato 4', 'Dato 5', 'Dato 6'],
  ],

  // Tema de la tabla
  theme: 'grid',  // 'striped', 'grid', 'plain'

  // Estilos generales
  styles: {
    fontSize: 10,
    cellPadding: 3,
    overflow: 'linebreak',
  },

  // Estilos para encabezados
  headStyles: {
    fillColor: [240, 240, 240],  // Color de fondo (gris claro)
    textColor: [0, 0, 0],         // Color de texto (negro)
    fontStyle: 'bold',
    halign: 'center',             // Alineación horizontal
  },

  // Estilos por columna
  columnStyles: {
    0: { halign: 'left', cellWidth: 50 },    // Primera columna
    1: { halign: 'center', cellWidth: 60 },  // Segunda columna
    2: { halign: 'right', cellWidth: 40 },   // Tercera columna
  },

  // Estilos alternos para filas
  alternateRowStyles: {
    fillColor: [245, 245, 245],
  },
});
```

5.4 OBTENER POSICIÓN FINAL
---------------------------
Después de dibujar una tabla, necesitas saber dónde terminó para continuar
dibujando otros elementos:

```typescript
autoTable(doc, {
  head: [['Col 1', 'Col 2']],
  body: [['Dato 1', 'Dato 2']],
});

// Obtener la posición Y final de la tabla
const finalY = (doc as any).lastAutoTable.finalY;
let yPosition = finalY + 10; // Continuar 10mm después de la tabla

// Ahora puedes dibujar más contenido
doc.text('Texto después de la tabla', 15, yPosition);
```

5.5 TABLA SIN ENCABEZADOS
--------------------------
```typescript
// Para tablas de totales o resúmenes
autoTable(doc, {
  body: [
    ['Subtotal :', 'S/ 1000.00'],
    ['IGV (18%) :', 'S/ 180.00'],
    ['Total :', 'S/ 1180.00'],
  ],
  theme: 'grid',
  columnStyles: {
    0: { halign: 'left', fontStyle: 'bold' },
    1: { halign: 'right' },
  },
});
```

5.6 FORMATO PERSONALIZADO DE CELDAS
------------------------------------
```typescript
autoTable(doc, {
  head: [['Producto', 'Precio', 'Cantidad', 'Total']],
  body: [
    ['Laptop', '2500.00', '2', '5000.00'],
    ['Mouse', '25.00', '10', '250.00'],
  ],
  columnStyles: {
    1: { halign: 'right' }, // Precio
    2: { halign: 'center' }, // Cantidad

```

6.4 FORMATO DE MONEDA
----------------------
```typescript
function formatCurrency(amount: number): string {
  return new Intl.NumberFormat('es-PE', {
    style: 'currency',
    currency: 'PEN',
    minimumFractionDigits: 2
  }).format(amount);
}

// Usar en el PDF
const total = 1250.50;
doc.text(`Total: ${formatCurrency(total)}`, 15, 20);
// Resultado: "Total: S/ 1,250.50"
```

6.5 FORMATO DE FECHA
---------------------
```typescript
function formatDate(dateString: string): string {
  return new Date(dateString).toLocaleDateString('es-PE', {
    day: '2-digit',
    month: '2-digit',
    year: 'numeric'
  });
}

// Usar en el PDF
const fecha = '2025-01-13';
doc.text(`Fecha: ${formatDate(fecha)}`, 15, 20);
// Resultado: "Fecha: 13/01/2025"
```

8.2 CREAR FUNCIONES REUTILIZABLES
----------------------------------
```typescript
function drawSection(doc: jsPDF, title: string, content: string, y: number): number {
  doc.setFont('helvetica', 'bold');
  doc.text(title, 15, y);
  doc.setFont('helvetica', 'normal');
  doc.text(content, 50, y);
  return y + 6; // Retornar nueva posición Y
}

// Usar:
let yPos = 20;
yPos = drawSection(doc, 'Nombre:', 'Juan Pérez', yPos);
yPos = drawSection(doc, 'Email:', 'juan@email.com', yPos);
```

8.3 MANEJO DE ERRORES
----------------------
```typescript
try {
  const doc = new jsPDF();
  // ... código de generación ...
  doc.save('documento.pdf');
  console.log('PDF generado exitosamente');
} catch (error) {
  console.error('Error al generar PDF:', error);

```

8.4 OPTIMIZACIÓN DE RENDIMIENTO
--------------------------------
- Generar PDFs grandes puede ser lento
- Mostrar un indicador de carga mientras se genera
- Evitar generar PDFs muy grandes (más de 50 páginas)

```typescript
const [loading, setLoading] = useState(false);

const generatePDF = async () => {
  setLoading(true);
  try {
    const doc = new jsPDF();
    // ... generar PDF ...
    doc.save('documento.pdf');
  } finally {
    setLoading(false);
  }
};
```

✅ VENTAJAS de jsPDF:
- No requiere servidor backend
- Genera PDFs instantáneamente en el navegador
- Compatible con todos los navegadores modernos
- Fácil de integrar en proyectos React/Vue/Angular

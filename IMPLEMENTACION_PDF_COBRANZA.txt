1. DESCRIPCIÓN GENERAL
================================================================================

Se implementó un sistema completo de generación de PDF para el módulo de
cobranza que permite crear facturas de compra en formato PDF de manera
automática al registrar una nueva compra.

La implementación incluye:
- Generación de PDF con jsPDF y jspdf-autotable
- Cálculo automático de totales (SubTotal, IGV 18%, Total)
- Tabla dinámica de productos/servicios
- Formato profesional con información del proveedor y documento

5. FUNCIÓN DE GENERACIÓN DE PDF
================================================================================

Ubicación: Función generarPDF() en [id]/page.tsx

5.1 PROCESO DE GENERACIÓN
--------------------------

1. Crear instancia de jsPDF:
   const doc = new jsPDF();

2. Obtener totales calculados:
   const totales = calcularTotales();

3. Agregar título centrado (tamaño 20):
   doc.text('FACTURA DE COMPRA', 105, 20, { align: 'center' });

4. Agregar información del documento (tamaño 12):
   - Tipo de comprobante
   - Serie-Número
   - Fecha de emisión

5. Agregar información del proveedor:
   - Nombre completo
   - RUC

6. Agregar forma de pago y moneda (lado derecho)

7. Generar tabla de productos usando autoTable:
   (doc as any).autoTable({
     startY: 95,
     head: [['#', 'Cantidad', 'Unidad', 'Descripción', 'P. Unitario', 'Total']],
     body: productosData,
     theme: 'striped',
     headStyles: { fillColor: [239, 161, 89] }  // Color naranja corporativo
   });

8. Agregar totales alineados a la derecha:
   - Sub Total
   - Descuentos
   - Valor Compra
   - IGV (18%)
   - TOTAL (tamaño 14, destacado)

9. Agregar observaciones si existen

10. Guardar PDF con nombre único:
    Factura_{serie}_{numero}_{timestamp}.pdf

5.2 CÓDIGO DE EJEMPLO
----------------------

const generarPDF = (data: FormData) => {
  const doc = new jsPDF();
  const totales = calcularTotales();

  // Título
  doc.setFontSize(20);
  doc.text('FACTURA DE COMPRA', 105, 20, { align: 'center' });

  // Información del documento
  doc.setFontSize(12);
  doc.text(`Tipo: ${data.idTipoComprobante === '1' ? 'Factura' : 'Boleta'}`, 20, 40);
  doc.text(`Serie-Número: ${data.serie}-${data.numero}`, 20, 47);
  doc.text(`Fecha: ${data.fechaEmision}`, 20, 54);

  // ... resto de la implementación

  // Guardar PDF
  const nombrePDF = `Factura_${data.serie}_${data.numero}_${new Date().getTime()}.pdf`;
  doc.save(nombrePDF);

  return nombrePDF;
};

6. CÁLCULO DE TOTALES
================================================================================

Ubicación: Función calcularTotales() en [id]/page.tsx

6.1 FÓRMULAS APLICADAS
-----------------------

1. Sub Total = Suma de (Cantidad × Valor Unitario) de todos los productos

2. Valor Compra = Sub Total - Descuentos

3. IGV = Valor Compra × 0.18

4. Importe Total = Valor Compra + IGV

6.2 CÓDIGO DE IMPLEMENTACIÓN
-----------------------------

const calcularTotales = () => {
  const subTotal = productos.reduce((sum, prod) => sum + prod.valorTotal, 0);
  const descuentos = watch("descuentos") || 0;
  const valorCompra = subTotal - descuentos;
  const igv = valorCompra * 0.18;
  const importeTotal = valorCompra + igv;

  return {
    subTotal: subTotal.toFixed(2),
    descuentos: descuentos.toFixed(2),
    valorCompra: valorCompra.toFixed(2),
    igv: igv.toFixed(2),
    importeTotal: importeTotal.toFixed(2)
  };
};

   - Agrega producto vacío al array

2. Eliminar Producto:
   - Solo permite eliminar si hay más de 1 producto
   - Filtra el producto por ID

3. Actualizar Producto:
   - Actualiza campo específico (cantidad, descripción, etc.)
   - Recalcula valorTotal automáticamente cuando cambia cantidad o valor unitario

7.3 CÁLCULO AUTOMÁTICO DE VALOR TOTAL
--------------------------------------

const handleProductChange = (id: number, field: keyof Producto, value: string) => {
  setProductos(prev => prev.map(prod => {
    if (prod.id === id) {
      const updated = { ...prod, [field]: value };
      if (field === 'cantidad' || field === 'valorUnitario') {
        const cantidad = parseFloat(field === 'cantidad' ? value : prod.cantidad) || 0;
        const valorUnit = parseFloat(field === 'valorUnitario' ? value : prod.valorUnitario) || 0;
        updated.valorTotal = cantidad * valorUnit;
      }
      return updated;
    }
    return prod;
  }));
};

9. FLUJO COMPLETO DE CREACIÓN
================================================================================

1. Usuario ingresa a /cobranza
2. Hace clic en "Nueva Compra"
3. Sistema navega a /cobranza/nuevo

6. Sistema valida datos
7. Si "Generar PDF Automáticamente" está activo:
   - Genera PDF automáticamente
   - Descarga el archivo
8. Muestra mensaje de éxito con nombre del PDF
9. Limpia el formulario
10. Redirige a /cobranza después de 1.5 segundos
